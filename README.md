# IAM MFA and SaaS Permissions Lab

## Overview
This project demonstrates the implementation of Multi-Factor Authentication (MFA) and cloud-based user permission management using Google Authenticator and Blogger. The lab focused on identity verification, delegated access, and SaaS administration concepts commonly used in enterprise IT and Identity & Access Management (IAM) environments.

The objective of this lab was to simulate real-world authentication and access control workflows used in modern cloud environments.

---

## Technologies Used
- Google Authenticator
- Gmail
- Blogger
- Multi-Factor Authentication (MFA)
- SaaS Administration
- Identity and Access Management (IAM)
  
---

## Objectives
- Configure Multi-Factor Authentication (MFA)
- Implement cloud-based authentication security
- Configure delegated user permissions
- Understand SaaS identity and access management concepts
- Simulate enterprise-style user administration workflows

---

## Tasks Completed

### 1. Configured Multi-Factor Authentication
- Created a dedicated Gmail account for lab testing
- Enabled Google 2-Step Verification
- Configured Google Authenticator for MFA
- Verified rotating authentication token functionality
- Tested secure authentication workflow

### 2. Configured SaaS Permissions
- Created a Blogger SaaS environment
- Configured delegated author permissions
- Added a secondary account with publishing access
- Simulated cloud-based access management workflows

### 3. Tested Delegated Access
- Logged into the delegated user account
- Verified successful permission assignment
- Created and published a test blog post
- Confirmed proper role-based access functionality
